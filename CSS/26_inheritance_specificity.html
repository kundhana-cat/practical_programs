02. CSS Specificity

Selector Priority

When multiple CSS rules target the same element, the selector with greater specificity wins.

Element Selector

Class Selector

ID Selector

Inline Style

Specificity Order

The general priority order is:

  • 1 Element selector
  • 2 Class / Attribute / Pseudo-class
  • 3 ID selector
  • 4 Inline style
  • 5 !important
