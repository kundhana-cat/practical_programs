CSS Pseudo-Classes

Explore interactive CSS states using :hover, :active, :focus and :visited pseudo-classes.

What are Pseudo-Classes?

CSS pseudo-classes allow elements to be styled based on their current state or user interaction. Try each example below to see the effect.

01

:hover

Applies styles when the mouse pointer moves over an element.

.box:hover
Move your mouse over me
02

:active

Applies styles while an element is being actively clicked or pressed.

button:active
03

:focus

Applies styles when an input or interactive element receives keyboard or mouse focus.

input:focus
04

:visited

Applies styles to links that the browser recognizes as already visited.

a:visited

Combined Interaction

Multiple pseudo-classes can be used together to create richer interactive experiences.

hover + active + focus

CSS Syntax

.button:hover {
    background: blue;
}

.button:active {
    transform: scale(0.95);
}

input:focus {
    border-color: purple;
}

a:visited {
    color: purple;
}
