Understanding calc()

The CSS calc() function allows you to perform mathematical calculations directly inside CSS properties. It is especially useful for creating flexible and responsive layouts.

CSS calc() Examples

Basic calc() Syntax

The general syntax of the CSS calc() function is:

width: calc( 100% - 40px );
padding: calc( 20px + 2vw );
font-size: calc( 1rem + 1vw );
