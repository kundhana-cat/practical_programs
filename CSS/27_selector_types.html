CSS Selectors

A practical demonstration of Universal, Element, Class, ID, Attribute and Grouping selectors.

1. Universal Selector

The universal selector is represented by * and targets every element.

* { box-sizing: border-box; }

2. Element Selector

An element selector targets all elements of a particular HTML type.

p { color: #cbd5e1; }

3. Class Selector

This paragraph uses the .highlight class selector.

Classes can be reused on multiple elements.

4. ID Selector

The heading above is styled using #special-heading.

5. Attribute Selector

Attribute selectors target elements based on their attributes or attribute values.

6. Grouping Selector

Grouped Heading

Multiple selectors can share the same CSS rule.

Selector Summary

  • * — Universal Selector
  • p — Element Selector
  • .highlight — Class Selector
  • #special-heading — ID Selector
  • input[type="email"] — Attribute Selector
  • h1, h2, p — Grouping Selector

Example CSS

* { box-sizing: border-box; }

p { color: gray; }

.highlight { color: blue; }

#special-heading { color: pink; }

input[type="email"] { border: 2px solid purple; }

h1, h2, p { font-family: Arial; }
