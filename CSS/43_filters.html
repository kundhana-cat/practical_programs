CSS Filters

Explore powerful CSS filter functions such as blur, grayscale, brightness, contrast, sepia, saturation and inversion.

Filter Effects

Each image below demonstrates a different CSS filter property.

Blur

Makes an image appear soft or out of focus.

filter: blur(5px);

Grayscale

Removes color from the image and creates a black-and-white appearance.

filter: grayscale(100%);

Brightness

Increases or decreases the brightness of the image.

filter: brightness(150%);

Contrast

Increases the difference between light and dark areas.

filter: contrast(180%);

Sepia

Adds a warm brown tone to an image.

filter: sepia(100%);

Saturation

Makes the colors more or less intense.

filter: saturate(250%);

Invert

Reverses the colors of an image.

filter: invert(100%);

Drop Shadow

Creates a shadow around the visible shape of an image.

filter: drop-shadow();

CSS Filter Syntax

/* Blur */
.image {
    filter: blur(5px);
}

/* Grayscale */
.image {
    filter: grayscale(100%);
}

/* Brightness */
.image {
    filter: brightness(150%);
}

/* Contrast */
.image {
    filter: contrast(180%);
}

/* Multiple filters */
.image {
    filter: grayscale(100%) contrast(150%);
}
