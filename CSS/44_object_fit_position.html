Object-Fit & Object-Position

Learn how CSS controls the size, cropping and positioning of images inside fixed containers.

Object-Fit

Object-fit controls how an image fits inside its container.

fill

Stretches the image to completely fill the container. The original aspect ratio may be distorted.

object-fit: fill;

contain

Keeps the complete image visible while maintaining its original aspect ratio.

object-fit: contain;

cover

Covers the complete container while maintaining the image's aspect ratio.

object-fit: cover;

none

The image keeps its original size without being resized to fit the container.

object-fit: none;

scale-down

Uses either none or contain, whichever results in a smaller rendered image.

object-fit: scale-down;

Object-Position

Object-position controls where the image is positioned inside its container.

center

Positions the image in the center of the container.

object-position: center;

top

Keeps the top part of the image visible when cropping occurs.

object-position: top;

bottom

Positions the image toward the bottom of the container.

object-position: bottom;

left

Positions the image toward the left side.

object-position: left;

right

Positions the image toward the right side.

object-position: right;

Practical Comparison

Object-fit and object-position can be used together.

object-fit: cover

cover + custom position

CSS Syntax

.image {
    width: 100%;
    height: 300px;

    object-fit: cover;
    object-position: center;
}

/* Other object-fit values */

.image {
    object-fit: fill;
}

.image {
    object-fit: contain;
}

.image {
    object-fit: none;
}

.image {
    object-fit: scale-down;
}

/* Object positioning */

.image {
    object-position: top;
}

.image {
    object-position: right center;
}

.image {
    object-position: 80% center;
}
