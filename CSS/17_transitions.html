CSS Transformations

Transformations allow elements to move, rotate, scale, or skew.

Rotate

Rotates the element by 45 degrees.

Translate

Moves the element horizontally and vertically.

Skew

Slants the element along the X and Y axes.

Multiple Transformations

Combines translate, rotate and scale.

Basic CSS Syntax

/* Transition */

.button {
    transition: all 0.4s ease;
}

.button:hover {
    background: pink;
    transform: translateY(-5px);
}


/* Transformations */

.box:hover {
    transform: scale(1.2);
}

.box:hover {
    transform: rotate(45deg);
}

.box:hover {
    transform: translate(50px, 20px);
}

.box:hover {
    transform: skew(15deg);
}
