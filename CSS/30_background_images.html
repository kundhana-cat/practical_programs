Background Positioning

CSS allows you to control exactly where a background image appears.

center

Places the background image in the center of the element.

cover

Scales the image so the entire element is covered.

no-repeat

Prevents the background image from repeating across the element.

CSS Used

.background {
    background-image: url("image.jpg");

    background-size: cover;

    background-position: center;

    background-repeat: no-repeat;
}

.left {
    background-position: left center;
}

.right {
    background-position: right center;
}

.top {
    background-position: center top;
}

.bottom {
    background-position: center bottom;
}
