Image Hover Effects

Create interactive and attractive image effects using CSS transitions, transforms and filters.

Hover Effect Gallery

Move your mouse over each image to see the CSS effect.

Zoom Effect

The image smoothly enlarges when the cursor moves over it.

transform: scale()

Grayscale to Color

The image starts in grayscale and becomes colorful on hover.

filter: grayscale()

Overlay Effect

A dark overlay and text appear when the image is hovered.

::after + opacity

Rotate Effect

The image slightly rotates while zooming on hover.

rotate() + scale()

Brightness Effect

The image becomes brighter and clearer when hovered.

filter: brightness()

Blur Effect

The image becomes sharp when the user hovers over it.

filter: blur()

Basic Hover Effect Code

.image-box {
    overflow: hidden;
}

.image-box img {
    width: 100%;
    transition: 0.5s ease;
}

.image-box:hover img {
    transform: scale(1.1);
}
