EXPERIMENT 11

Internal & External CSS

The cards below demonstrate two different ways of applying CSS styles to HTML elements.

🎨
EXTERNAL CSS

External Styling

External CSS is written in a separate .css file and connected to the HTML document using the <link> element.

<link rel="stylesheet" href="style.css">
✓ Reusable across multiple pages
✨
INTERNAL CSS

Internal Styling

Internal CSS is written inside the <style> element within the HTML document's <head>.

<style>
  .card {
    color: blue;
  }
</style>
✓ Useful for page-specific styling
