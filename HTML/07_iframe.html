What is an iframe?

An iframe, or inline frame, allows another HTML document or external webpage to be displayed inside the current webpage.

<iframe
   src= "page.html"
   title= "Embedded Page"
></iframe>
🧩

Where are iframes used?

Iframes can be used to embed maps, videos, documents, online tutorials, dashboards and other supported external content into a webpage.

<iframe
   width= "100%"
   height= "400"
   src= "URL"
></iframe>
